# Project Instructions

## Project

This repository contains a Telegram client for Android built from scratch
using TDLib.

## Current phase

We are currently implementing the functional client core.

Do NOT spend time on final visual design.

The final application will eventually support:
- iOS-like UI
- Material UI
- Liquid Glass UI
- extensive UI customization

These are NOT priorities during the current development phase.

## Platform

Android only.

Do not implement:
- desktop application
- web application
- iOS application
- cross-platform UI

## Technology

- Kotlin
- Android SDK
- Jetpack Compose
- TDLib
- Kotlin Coroutines
- Flow / StateFlow
